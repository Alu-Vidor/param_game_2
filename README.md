# План

Веб-приложение для параметрической задачи квадратичного программирования. Помогает выбрать производственный план, увидеть загрузку ресурсов и понять, как решение меняется при изменении параметра.

Сайт: https://alu-vidor.github.io/param_game_2/

## Возможности

- Производственная модель из переданного Python-ноутбука: цены, затраты, ресурсы, мощности, матрицы M и H.
- Общая задача `max xᵀAx + b(t)ᵀx + c(t)` при `Kx ≤ l(t)` и `x ≥ 0`.
- До 6 переменных, до 15 ограничений в общей модели и до 10 ресурсов в редакторе производства.
- Фиксированная сетка или автоматическое увеличение числа точек по стабильности коэффициентов.
- Рациональное приближение каждой переменной со степенями числителя и знаменателя от 0 до 4.
- Критерий ноутбука по ошибке плана и расширенный взвешенный критерий из теории.
- Численный план, ограничения, графики, таблица, формулы и диагностика точности.
- Несколько моделей, копирование, локальное сохранение, импорт и экспорт JSON, таблица CSV.
- Расчёт в отдельном Web Worker; его можно остановить. Данные модели не отправляются на сервер.

Исходный пример содержит 2 продукта, 3 ресурса и диапазон `t = 1…10`. Все результаты рассчитываются из введённых данных. Дробный выпуск допускается, целочисленная оптимизация не выполняется.

## Математика

Постановка сохранена. Явные программные ошибки исходного ноутбука исправлены: лишнее деление стационарной точки, порядок коэффициентов, неполная проверка ККТ и отбрасывание корректных точек из-за статуса оптимизатора. Формулы, ограничения метода и контрольные значения описаны в [docs/math.md](docs/math.md).

Непрерывное приближение не является автоматически допустимым планом между узлами. Приложение отдельно проверяет плотную сетку, знаменатели и ошибки. Критерий сходимости коэффициентов не гарантирует точность оптимального плана.

## Локальный запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Первый расчёт загружает Pyodide 0.28.3, NumPy и SciPy с jsDelivr. Нужен интернет; дальнейшие расчёты в открытой вкладке используют загруженный модуль. Интерфейс работает без сервера приложений. Названия и результаты хранятся в `localStorage` данного браузера. Для резервной копии используйте JSON.

## Проверки

```sh
npm test
npm run build
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p 'test_*.py' -v
```

Python-тесты проверяют аналитические решения, активные ограничения, несовместность, вогнутость, аппроксимацию, полюса и автоматический подбор сетки. TypeScript-тесты проверяют импорт и сохранность структуры данных.

## Публикация

GitHub Pages должен использовать источник **GitHub Actions**. Workflow проверяет TypeScript и Python, собирает `dist/` и публикует его при push в `main`. Относительные пути Vite позволяют работать в подпапке `/param_game_2/`.
