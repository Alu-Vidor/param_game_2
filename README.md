# Параметрическое квадратичное программирование

Одностраничный калькулятор для задачи max f(x,t) = xᵀA(t)x + b(t)ᵀx + c(t) при K(t)x ≤ l(t).

Сайт: https://alu-vidor.github.io/param_game_2/

## Возможности

- Элементы A(t), b(t), c(t), K(t), l(t) принимают числа, многочлены и дроби. Пример ввода — \`(-1-t^2)/(1+t)\`.
- От 1 до 6 переменных и от 0 до 21 строки K. Границы xᵢ ≥ 0 включаются отдельно. Готовый пример содержит 2 переменные, 5 строк K и 2 такие границы.
- Численный максимум в расчётных узлах для вогнутой целевой функции. Проверка знаменателей исходных коэффициентов и численная проверка условий Куна — Таккера.
- Рациональное приближение решения с учётом ограничений в узлах. Степени числителя и знаменателя от 0 до 4, взвешенные ошибки решения и цели.
- Ввод, запуск и результат на одной странице. Графики, таблица, формулы и диагностика в раскрывающихся блоках.
- Модели сохраняются локально. Доступны JSON и CSV. Модели из прежней версии преобразуются к математической записи при загрузке.

## Математика

Формулы, ограничения численных методов и контрольные значения приведены в [технической документации](docs/math.md).

Непрерывное приближение не является автоматически допустимым планом между узлами. Приложение отдельно проверяет плотную сетку, знаменатели и ошибки. Критерий сходимости коэффициентов не гарантирует точность оптимального плана.

## Локальный запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Первый расчёт загружает Pyodide 0.28.3, NumPy и SciPy с jsDelivr. Нужен интернет; дальнейшие расчёты в открытой вкладке используют загруженный модуль. Интерфейс работает без сервера приложений. Названия и результаты хранятся в `localStorage` данного браузера. Для резервной копии используйте JSON.

## Проверки

```sh
npm test
npm run build
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p 'test_*.py' -v
```

Python-тесты проверяют аналитические решения, активные ограничения, несовместность, вогнутость, аппроксимацию, полюса и автоматический подбор сетки. TypeScript-тесты проверяют импорт и сохранность структуры данных.
